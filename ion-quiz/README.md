# イオンと化合物ドリル

プリント「イオンの名称と化合物」の内容を、中学生が復習できるWebアプリにしたものです。

- `index.html` … アプリ本体（ブラウザで開くだけで動きます）
- `data.js` … イオンと化合物のデータ（**編集するのはこのファイルだけ**）

## できること

| タブ | 内容 |
| --- | --- |
| れんしゅう | 4択 or 「紙に書いて答え合わせ」で出題。まちがえた問題は「苦手」に記録され、あとで苦手だけ復習できます |
| 一覧表 | プリントと同じ表。名前・化学式をかくして暗記チェックができます |
| テスト用紙 | ランダムに問題をえらんでテスト用紙を作成（年・組・番・名前欄つき、解答表示の切りかえ、印刷） |

問題の種類：イオン式→名前／名前→イオン式／化学式→名前／名前→化学式／イオンの組み合わせ→化学式

## データの編集

`data.js` をテキストエディタ（GitHub上なら鉛筆アイコン）で開いて書きかえます。
使い方はファイルの先頭にコメントで書いてあります。

- 化学式の数字は自動で下つき文字になります（`Al2(SO4)3` → Al₂(SO₄)₃）
- 化合物にならない組み合わせは `null` にすると出題されません

## 画像から読み取ったときの修正点

- 「硝酸銀」（プリントでは「硝酸鉛」に見える部分）を硝酸銀に統一
