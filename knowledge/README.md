# 野球 knowledge

野球の指導、練習に関する知識を、出典と根拠の強さが分かる形で蓄積するフォルダです。

```
knowledge/
├── README.md                    … このファイル
├── _templates/                  … 動画ノート、テーマ、更新候補のテンプレート
├── sources/
│   └── youtube/
│       ├── CHANNELS.md          … 優先参照チャンネルと運用ルール
│       ├── macs-trainer-room/
│       ├── turning-point/
│       ├── driveline-baseball-japan/
│       ├── konchan-baseball/
│       └── nikkansports-baseball/
├── topics/                      … テーマ単位に統合した知識（本体）
└── site-update-proposals/       … Webサイトの更新候補（提案のみ）
```

## 流れ

1. **情報収集**：`sources/youtube/CHANNELS.md` の優先チャンネルから、テーマに関連する動画を選び、動画ノートを作る。
2. **統合**：`topics/<テーマ>.md` に、複数の情報源の主張を比較・統合する。
3. **サイトへの反映提案**：既存ページと比べ、`site-update-proposals/` に更新候補を書く。Webサイト本体は、ユーザーの許可があるまで変更しない。

根拠レベル（A 研究 / B データ / C 専門家の見解 / D 指導経験 / E 個人の仮説）の定義は `sources/youtube/CHANNELS.md` にあります。
