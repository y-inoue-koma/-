## 使うとき

「YouTubeから○○について調べて」「打撃の knowledge を強化して」「投手育成について調べて」のような指示を受けたら、次の手順で進める。

1. **選ぶ**: 上の5チャンネルから、テーマに関係する動画を探して選ぶ。チャンネルの全動画を保存することはしない。5チャンネルで足りないときは、その旨を書いてから他の情報源を使う。
2. **確認する**: 動画ごとに次の情報を確認する。取れなかった項目は「取得できず」と書き、推測で埋めない。
   - 動画タイトル / URL / 公開日 / チャンネル名 / 動画説明
   - 字幕または文字起こし（自動字幕なのか、手動字幕なのかも書く）
   - 根拠にする箇所のタイムスタンプ
3. **分析する**: [動画ノートのテンプレート](../../templates/video-note.md) を使い、チャンネルのフォルダに動画ノートを作る。要約だけで終わらせず、主張・理由・対象の選手・練習方法・指導のキュー・注意点・根拠の種類・高校野球で実践できるかを書き出す。練習ドリルは「目的 → 対象選手 → 方法 → 回数・時間 → 指導ポイント → よくあるエラー → 修正方法」の順に整理する。
4. **テーマごとにまとめる**: [テーマノートのテンプレート](../../templates/topic.md) を使い、`knowledge/topics/<テーマ>.md` に統合する。動画ごとの要約を並べるだけにはせず、情報源どうしを比べて、共通点・相違点・根拠の強さ・高校野球でのやりやすさを整理する。
5. **サイトと比べる**: 関係するサイトのページと比べ、`knowledge/site-updates/` に更新候補を書く（[テンプレート](../../templates/site-update-candidate.md)）。**サイト本体（`*.html` / `*.js` / `*.css` など）は、許可を得るまで変更しない。**

## 扱い方

- **転載しない**: 字幕や発言を長く引用しない。分析と要約として書き、必要な箇所はタイムスタンプで示す。
- **根拠の種類を区別する**: 主張ごとに、次のどれに当たるかを付ける。

  | ラベル | 意味 |
  |---|---|
  | `研究` | 論文や研究結果が示されている（出典を確認できたものに限る） |
  | `データ` | 計測値や統計が示されている（研究論文ではないもの） |
  | `専門家見解` | トレーナー・研究者・指導者などが専門の立場から述べたもの |
  | `指導経験` | 現場での指導経験に基づく経験則 |
  | `個人の仮説` | 根拠がはっきり示されていない考えや推論 |

- **批判的に読む**: 優先情報源であっても、他の動画・資料と食い違う点、対象（プロ・大学・高校・中学）の違い、宣伝の意図、ケガのリスクを確かめる。
- **不確かなものは不確かと書く**: 確認できないことは「未確認」とはっきり書く。
