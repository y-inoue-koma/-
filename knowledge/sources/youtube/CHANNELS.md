## 運用ルール

### 1. 起点になる指示

たとえば次のように指示されたときに、このルールを使います。

- 「YouTubeから○○について調べて」
- 「打撃についてknowledgeを強化して」
- 「投手育成について調べて」
- 「スイング速度について調べて」

### 2. 動画の選び方

1. テーマをキーワードに分解する（例：スイング速度 → バットスピード、スイングスピード、スイング軌道、回旋、オーバーロード／アンダーロード、ウエイトトレーニング）。
2. 上の5チャンネルから、テーマに**関連する動画だけ**を選ぶ。**チャンネル内の全動画を無条件に保存しない。**
3. 選んだ理由（どの論点を扱っているか）を動画ノートに書く。
4. 5チャンネルで足りない、または根拠が弱い場合は、他の情報源も探し、そのことを明記する。

### 3. 確認する項目

可能な範囲で、次の項目を確認します。

| 項目 | 取得できないときの書き方 |
|---|---|
| 動画タイトル | 「未確認」 |
| URL（`https://www.youtube.com/watch?v=<ID>`） | 「未確認」 |
| 公開日 | 「未確認」 |
| チャンネル名 | 「未確認」 |
| 動画説明（概要欄） | 「未確認」 |
| 字幕または文字起こし | 「取得不可（理由）」。字幕の種類（手動、自動生成）も書く |
| 該当タイムスタンプ | 「未確認」 |

**取得できなかった情報は推測で埋めない。** タイトルやサムネイルだけで内容を推定した場合は、その旨を明記し、根拠レベルを下げる。

### 4. 動画ごとの分析項目

単純な要約だけでなく、次の項目を取り出します。テンプレートは [`knowledge/_templates/video-note.md`](../../_templates/video-note.md) です。

- 何を主張しているか
- なぜそう考えているのか
- どのような選手を対象としているか
- 具体的な練習方法
- 指導するときのキュー（声かけ）
- 注意点
- 科学的根拠が示されているか
- 経験則なのか
- 他の動画や資料と一致しているか
- 高校野球で実践可能か

**練習ドリル**は次の順序で構造化します。

目的 → 対象選手 → 方法 → 回数・時間 → 指導ポイント → よくあるエラー → 修正方法

### 5. 根拠レベル（主張ごとに付ける）

| レベル | 区分 | 例 |
|---|---|---|
| A | 研究による裏付け | 査読論文やメタ分析が引用されている（論文名などを確認できたもの） |
| B | データ | 計測データ（バットスピード、球速、回転数など）が示されている。n数や計測方法を書く |
| C | 専門家の見解 | 資格や実績が確認できる専門家（トレーナー、研究者、プロ指導者など）の説明で、データの提示はない |
| D | 指導経験 | 「多くの選手で効果があった」などの経験則 |
| E | 個人の仮説 | 検証されていない考えや、本人の感覚 |

- 1本の動画でも主張ごとにレベルが違うことがあるため、動画単位ではなく**主張単位**で付ける。
- 「研究では〜」と言っているが出典が示されていない場合は、A にしない（「出典未提示の研究言及」と書き、C または D 扱いにする）。
- 優先チャンネルの内容でも、他の資料と矛盾する場合や、高校生に当てはめるにはリスクがある場合は、そのことを書く。

### 6. テーマ単位の統合

動画ノート（`sources/youtube/<channel>/`）は**素材**です。知識の本体は **`knowledge/topics/`** にテーマ単位でまとめます。テンプレートは [`knowledge/_templates/topic.md`](../../_templates/topic.md) です。

- 「動画Aの要約」「動画Bの要約」を並べるだけにしない。
- 同じテーマについて複数の情報源がある場合は、次の観点で比較する。
  - 共通している考え方
  - 異なる考え方（なぜ違うのか。対象選手や目的の違いなど）
  - 科学的根拠が強いもの
  - 経験則が中心のもの
  - 高校野球で実践しやすいもの
- 各主張には、出典の動画ノートへのリンクとタイムスタンプを付ける。

### 7. Webサイトへの反映（提案のみ）

知識を追加した後は、現在のWebサイト（リポジトリ直下の `index.html`、`schedules.html`、`app.js`、`ion-quiz/` など）を確認し、関連するページがあれば次の3点を比較します。

1. 現在のサイト
2. 新しく得られた知識
3. 追加・修正すると良い内容

結果は `knowledge/site-update-proposals/` に**更新候補**として保存し、ユーザーに提示します。テンプレートは [`knowledge/_templates/site-update-proposal.md`](../../_templates/site-update-proposal.md) です。

**ユーザーの許可なしにWebサイト本体のファイルは変更しない。**

### 8. 著作権と転載

- 字幕や文字起こしを大量に転載しない。自分の言葉で分析・要約し、引用は主張を示すのに必要な短い範囲にとどめる。
- 引用には必ず動画URLとタイムスタンプを付ける。
- 文字起こし全文をリポジトリに保存しない。

このファイルの表と `knowledge/sources/youtube/<channel-slug>/README.md` の両方を更新します。フォルダ名は、半角英小文字とハイフンを使います。
