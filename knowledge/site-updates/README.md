# サイト更新候補

書式は [テンプレート](../templates/site-update-candidate.md) を使う。**許可を得るまでサイト本体は変更しない。**

- リポジトリにあるページ: `index.html`（ダッシュボード）、`schedules.html`（予定表）、`ion-quiz/`
- ナビにはリンクがあるが、ファイルがないページ: `menus.html`（練習メニュー）、`members.html`、`records.html`、`absences.html`
